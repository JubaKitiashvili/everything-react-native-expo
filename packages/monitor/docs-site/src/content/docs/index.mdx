`@erne/monitor` is a React Native / Expo SDK plus a self-hostable dashboard, an
MCP server so an agent like Claude can query your monitoring data, and an
**optional, separate** AI agent that can open a fix PR against your repo. Your
telemetry stays on **your** infrastructure — or, in local-only mode, never
leaves the device. MIT-licensed, with no vendor ingestion endpoint to point a
DSN at.

## Quickstart

Three lines from zero to a live event stream:

<Code
  code={`npx expo install @erne/monitor                  # 1. add the SDK
npx @erne/monitor init                          # 2. wires <MonitorProvider> + babel plugin
npx @erne/monitor dashboard --open              # 3. open the local dashboard, reload your app`}
  lang="bash"
/>

`init` is idempotent (re-run safe; `--dry-run` previews). See
[Getting started](/getting-started/) for the manual wiring, native build steps,
and how to point the SDK at the dashboard over WebSocket.

## What you get

<CardGrid>
  <Card title="Crash & ANR capture" icon="error">
    JS exceptions and unhandled rejections, plus native crashes via a
    signal-safe handler — persisted across process death and drained on the
    next launch. A watchdog thread detects ANRs and captures the real
    main-thread stack on iOS and Android.
  </Card>
  <Card title="Performance" icon="rocket">
    Dual-thread FPS (native UI vs JS), Fabric commit latency, a Hermes CPU
    profiler with a flamegraph in the dashboard, frame-drop and long-task
    detection, and memory + thermal polling. RSC projects also get server
    render time, payload size, and streaming metrics.
  </Card>
  <Card title="Session replay" icon="seti:video">
    Each app-run is a session with event and crash counters. PII-masked
    screenshots in a ring buffer, layout snapshots, and navigation-triggered
    visual repro reconstruct what the user saw — without exposing their data.
  </Card>
  <Card title="AI-assisted fix PRs" icon="seti:github">
    A separate, confidence-gated agent (`@erne/monitor-ai-fix-pr`) turns a crash
    group into a candidate fix and opens a pull request via the GitHub API. Its
    confidence decays automatically as your team merges or rejects proposals.
  </Card>
  <Card title="MCP integration" icon="seti:json">
    A Model Context Protocol server exposes your telemetry — crash groups,
    events, sessions, bug reports, symbols, DSAR — to Claude and any MCP-aware
    client. Tools are read-only by default; the one mutating tool needs an
    explicit write grant.
  </Card>
  <Card title="Self-hostable dashboard" icon="laptop">
    A Node server that ingests events, groups crashes, and serves the UI. SQLite
    by default for local dev, PostgreSQL for production. Multi-tenant RBAC
    (Owner / Member / Viewer) plus rotatable, revocable ingest keys.
  </Card>
  <Card title="Privacy-first" icon="approve-check">
    On-device PII sanitization (emails, phone numbers, auth headers, sensitive
    URL params) runs before transport — redacted data never leaves the app.
    Per-category consent, a CCPA "do not sell" signal, an Apple Privacy Manifest,
    and DSAR export / delete APIs.
  </Card>
  <Card title="Pay for what you use" icon="puzzle">
    Tree-shakeable subpath imports (`@erne/monitor/performance`,
    `@erne/monitor/network`, `@erne/monitor/ai`, …) pull only the collectors and
    code you name, so an app that wants crashes alone doesn't ship the profiler.
  </Card>
</CardGrid>
